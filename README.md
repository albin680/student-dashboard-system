# Student Dashboard System

A Django-based dashboard system for students and faculty.

1. Features

- Student Login & Faculty Login
- Student Dashboard
- Faculty Dashboard
- Enquiry Submission
- Enquiry History
- Notifications
- Chatbot UI
- Dark/Light Mode

2. Technologies Used

- Django
- HTML
- CSS
- JavaScript

3. Installation

```bash
git clone https://github.com/albinjoy680/student-dashboard-system.git
```

```bash
cd student-dashboard-system
```

```bash
pip install -r requirements.txt
```

```bash
python manage.py migrate
```

```bash
python manage.py runserver
```
